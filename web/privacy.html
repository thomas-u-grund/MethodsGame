The Secret of the Lost Codebook

Privacy

In short: the game can keep anonymous counts of how it is played, so that the author can see where players get stuck. It never keeps your name, email address, IP address or anything you type, and you can switch it off at any time.

Your choice on this device

Anonymous play statistics:

You can also change this inside the game, under Settings. The choice is stored only in this browser and takes effect at once, also in a game tab that is already open.

What is recorded

  • which rooms are entered, and for how long each stays open;
  • which story steps are reached, and which things are clicked (and whether looked at, talked to, picked up or used);
  • which dialogue answers are chosen;
  • when the hint button is used, and which Lessons Learned slides and the ending are reached;
  • your screen size (rounded to the nearest hundred pixels), whether it is a touch screen, your control setting, whether voice-only is on, and whether you are continuing a saved game;
  • that the game was opened through a course link (yes or no; the course code itself is not recorded).

Each visit is given a random number that exists only while the page is open. It is not stored on your device, so a later visit cannot be linked to an earlier one.

The purpose is to improve the game, for example by finding a puzzle where many players leave, and to describe in general terms how it is used. The anonymous counts may be summarised in teaching or research writing about the game.

What is not recorded

  • your name, email address, student number or any account;
  • your IP address (the game does not store it);
  • anything you type;
  • cookies, advertising or tracking identifiers: none are set.

The statistics are kept apart from the bonus-point service for instructors, which is separate, optional and used only when you choose to claim a point.

For the bonus points, the game gets a random play number from the server when you start, and tells the server each time you finish an act. That is how the last screen can give you a completion code that works only once. The play number says nothing about who you are and is not linked to these statistics; unfinished games are deleted after 90 days, the rest after one year. Your student number and name are sent only if you claim a point.

The game also respects your browser's Do Not Track and Global Privacy Control signals: if either is on, nothing is recorded and the Settings switch is disabled.

Who is responsible

The game is hosted on Cloudflare, which handles requests technically and may see IP addresses as any web host does; the game itself does not store them. The anonymous counts are kept in a Cloudflare database.
