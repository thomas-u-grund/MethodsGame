Set up a course

Every course is one small file in courses/ next to the game, e.g. courses/methods-ws26.json. Students play via the-secret-of-the-codebook.html?course=methods-ws26, and you check here via verify.html?course=methods-ws26. Copy courses/example.json, change the texts, and put a fresh secret in it:

(press the button)

The code is tied to the student ID, the date and your course's secret, so it cannot be copied to another name or guessed. The game is a static website, so a technically determined student could read the secret out of the course file. Only a server could stop that. Change the secret each term.
